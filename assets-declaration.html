口径：逐类披露本作中 AI 参与生产的资产、所用工具、人工加工环节，以及 纯人工 / 程序生成的部分与 第三方素材授权情况。

一、AI 生成资产

合计：3D 模型 14 个 glb（含源 4 级 LOD：lod0–lod3，运行时按屏占比切级）； 音频 30 条（28 音效 + 2 BGM）；应用图标五件套；商店详情页宣传素材若干。

类别内容工具 / 来源人工加工
单位 3D 模型 虫族三形态（镰爪战虫 / 重甲虫王 / 幼生工虫），带骨骼蒙皮与 PBR 贴图（D/N） 云端多视图生成管线，输入为下方 AI 概念四视图 经转换脚本统一缩放 / 贴地 / 材质入库；骨骼动画由程序烘焙（见二）
概念图 上述三形态 + 兽人酋长 / 战士 / 工虫 + 砂金矿，共 7 组 ×4 视图 云端图像生成（多视图概念评审流程） 人工评审定稿
场景物件 砂金堆四档耗损模型、瓦砾堆变体 ×3、矿格砂金矿块、建筑三件（石砌矮墙 / 石砌金帽塔 / 青玉晶体核心） 同上管线（含文本直出） 摆放口径（缩进 / 贴地 / 确定性取模）为代码实现
音效 全部 28 条：虫族 6 + 兽人族 6 + 场景 15 + 开屏 stinger 1 云端音效生成（其中 9 条为 TapTap 制造平台生成额度） 音量分级、轮换池防同帧互掐为代码实现
战斗音乐 对局 BGM 与结算 BGM 各 1 云端音乐生成（结算 BGM 为制造平台生成额度） 循环点、音量与终局切换由代码设定
应用图标 主图 / Android 192 / 自适应前景与背景 / Windows 多尺寸 .ico TapTap 制造平台生成额度 定稿选取与各平台导出接线由人工完成
商店宣传素材 头图 ×1 + 宣传图 ×4（1920×1080） TapTap 制造平台生成额度 构图拼配与选用由人工裁定（详情页另置实机图 5 张，非 AI）

二、程序生成资产（非 AI、非动捕）

  • 单位动画：15 条基础动作（Idle / Crawl / Attack / Hurt / Death ×3 形态）由离线脚手架对绑定骨架 程序化烘焙，不使用动作捕捉、不使用 AI。
  • 地形：64×64 战场高度场（脊线 / 盆地 / 核心台地 + 外围噪声山岭）为 固定种子值噪声程序生成，逐局一致；叠加程序化地形蓝图（fbm / warp / ramp / landmark 积木， canyon / shale / ember 三预设逐局轮换）。视图种子与仿真严格隔离，同样非 AI。

三、AI 辅助编写（人工裁定与署名）

  • 游戏代码（模拟核心 / 视图 / HUD / 验证体系）：由 AI 在作者逐项裁定下编写； 架构、数值、波次表、验证闸口径均为人工决策，确定性对拍（逐 tick 指纹）机器验证。
  • 开发日志：AI 起草、作者审定署名后发布。

四、纯人工部分

  • 玩法设计（「放墙改道」核心机制、改道经济、波次节奏）
  • 关卡夹具（64×64 地形语义：岩脊、咽喉、盆地开门陷阱、矿位）
  • 全部数值与平衡裁定、验证体系（21 项闸：单测 + 验收探针 + 截图像素校验）设计
  • 详情页实机图 5 张（对局内实拍渲染，非 AI）

五、引擎与第三方素材

  • 引擎：Godot Engine 4.7.2 stable (mono)（官方导出模板）；未随本作引入任何第三方插件。
  • 第三方素材 3 项：
    1. Noto Sans SC 字体（SIL OFL 1.1，版权归 Adobe）——随包附许可全文与声明件。
    2. Noto Serif SC Bold 按需子集（SIL OFL 1.1，版权归 Adobe；由同项目可变字体实例化 wght=700 并子集化，属 Modified Version）——仅用于标题字。
    3. 地表纹理 4 张（ambientCG Ground093C / Rock061 漫反射 + 法线，CC0 1.0， 无署名义务；Roughness 通道未随包）。
  • 引擎自带默认资源（图标 / 主题 / 示例）未用于本作代表性内容。
